# Validação

Os resultados atuais da revisão completa estão em [REVISAO-FINAL.md](REVISAO-FINAL.md). A lista de URLs verificadas está em [LINKS.md](LINKS.md).

Execute npm run check, npm run build, npm test, npm run qa e npm run review. Os testes de navegador usam um servidor próprio com porta dinâmica e não dependem de um endereço de desenvolvimento fixo.

Lighthouse pode ser executado com node scripts/lighthouse.mjs. Resultados de sessões anteriores não são apresentados como novas medições.
